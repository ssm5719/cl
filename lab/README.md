# 클라우드러닝 수정 실험실

**이 폴더는 수정안 미리보기이며 실제 서비스 코드가 아닙니다.** 배포 없이 "지금 화면"과 "수정안"을 전환하며 비교하려고 만든 정적 페이지입니다.

## 여는 법

빌드가 없습니다. `index.html` 을 브라우저로 열면 됩니다. 로컬에서 바로 열면 미리보기 iframe이 막히므로, 간단한 서버를 띄우는 쪽이 확실합니다.

```bash
python3 -m http.server 8080
# http://localhost:8080/lab/
```

GitHub Pages가 켜져 있으면 `https://ssm5719.github.io/cl/lab/` 로도 열립니다.

## 쓰는 법

- 위쪽 **관리자 · 선생님 · 학생 · 404** 탭으로 화면 묶음을 고릅니다.
- **[현재] / [수정안]** 으로 같은 화면을 전환해 비교합니다.
- **[라이트] / [다크]** 로 테마를 바꿉니다.
- 왼쪽 **이 화면의 수정** 목록에서 수정 하나씩 켜고 끌 수 있습니다. 찾기 칸에 번호(예: `X3`)를 넣으면 그 수정만 봅니다.
- 미리보기 안에서 사이드바 메뉴를 누르면 그 화면으로 넘어갑니다.

## 폴더

| | |
| --- | --- |
| `index.html` | 실험실 화면 |
| `fixes.js` | 수정 목록. 건마다 현재 값 · 바꿀 값 · CSS · 마크업 · 적용 스크립트 |
| `css/` | `cl-tokens.css`(토큰) · `base.css`(공통 레이아웃) · `components.css`(공통 컴포넌트) · 화면별 `manager` `teacher` `student` `public` |
| `screens/` | 화면별 미리보기 HTML |
| `img/` `fonts/` `vendor/` | 로고 · Pretendard · Toast UI 편집기 |

## CSS 층

관리자 · 선생님 · 학생 · 학원 페이지가 **같은 공통 CSS 세 파일**(`cl-tokens.css` · `base.css` · `components.css`)을 함께 씁니다. 화면별 CSS는 토큰을 정의하지 않고 `var(--cl-…)` 로 읽기만 합니다. 두 화면 묶음에서 같은 부품을 쓰게 되면 공통 층으로 올립니다.
