# PageHead

화면 맨 위: 상위 메뉴, 제목, 화면 단위 버튼, 설명.

- `cl-page__head--row`: 가로 배치, 아래쪽 맞춤, 사이 12px, 줄바꿈 허용. 아래 여백 20px.
- 상위 메뉴 `cl-page__parent`: `cl-fs-caption` `cl-ink-muted`, 아래 4px.
- 제목 `cl-page__title`: `cl-fs-page-title`(24px) 700, 줄높이 1.35, 자간 -0.025em.
- 설명 `cl-page__meta`: `cl-fs-caption` `cl-ink-muted`, 위 4px.
- 버튼은 `cl-toolbar__spacer` 뒤 오른쪽에 둔다.
- 화면 좌우 여백 `cl-ws-gutter`(16~40px), 위 24px. 모바일 20px 16px.

## 화면 폭

관리자 화면은 가로 100%로 늘어나되, 본문은 최대 `cl-w-page-max`(1,680px)에서 멈추고 **왼쪽 정렬**한다(사이드바 바로 옆에서 시작, 가운데로 옮기지 않는다). 1,680px 은 1920 모니터에서 사이드바 240px 을 뺀 폭이라 1920 이하 화면은 그대로이고, 2560 · 울트라와이드에서만 오른쪽이 빈다. 너무 넓으면 표 한 줄을 끝까지 따라가기 어렵기 때문이다. 고정 폭으로 디자인하지 않고 1280 · 1440 · 1920 · 2560px 에서 확인한다(1280 이하는 사이드바가 아이콘 줄 56px).

| 화면 종류 | 틀 | 최대 폭 |
| --- | --- | --- |
| 목록 · 표 · 통계 · 대시보드 | `cl-page cl-page--wide` | 1,680px(`cl-w-page-max`) |
| 그림 카드가 여러 개인 설정(메인페이지 · 배너) | `cl-page cl-page--wide` | 1,680px |
| 입력 · 설정(만들기 · 수정 · 학원 소개 · 메뉴 · 허용 IP) | `cl-page` | 880px |
| 왼쪽 목차가 있는 설정(학원 설정) | `cl-page` + 목차 폭 | 1,064px(880 + 목차 160 + 사이 24) |

입력 칸 하나는 Field 규칙대로 최대 420px. 2단 입력은 880px 틀 안에서 칸 하나 약 400px.

## 지금 어긋난 곳

화면마다 머리 구성이 다르다 (점검 1).

| 화면 | 상위 메뉴 | 제목 줄에 있는 것 | 설명 |
| --- | --- | --- | --- |
| 선생님 목록 | 있음 | 보기 전환 · 노출 순서 · 선생님 생성 | 2문장 |
| 학생 목록 | 있음 | 엑셀 다운로드 · 엑셀 일괄 처리 (주 버튼 없음) | 2문장 |
| 과목 목록 | 있음 | 과목 추가 | 3문장 |
| 강좌 관리 (선생님) | 없음 | 검색 · 보기 전환 · 강좌 생성 | 없음 |
| 대시보드 | 없음 | 기간 · 날짜 범위 · 새로고침 | 없음 |
