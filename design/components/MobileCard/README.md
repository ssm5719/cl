# MobileCard

900px 이하에서 표(`cl-table`)가 바뀌는 카드형 행. 따로 만드는 컴포넌트가 아니라 같은 표 마크업이 CSS로 바뀐다.

- `thead` 를 숨기고 각 `tr` 을 2열 격자(`minmax(0,1fr) auto`, 사이 4px 12px)로 바꾼다. 행 위아래 12px, 아래 1px `cl-grid-row`.
- `data-primary` 칸이 한 줄 전체를 쓰는 카드 제목이 된다.
- 나머지 칸은 `data-label` 을 "이름 · " 처럼 앞에 붙여 보여 준다(`cl-fs-caption`, `cl-ink-muted`).
- 행 메뉴(⋯)는 마지막 칸이라 별도 줄을 차지한다.

## 지금 어긋난 곳

- 선생님 카드 하나가 5줄(아이디 / 이름 · 휴대폰 / 과목 · 등급 / 등록일 / ⋯)이다. 25명이면 스크롤이 길다 (점검 5).
- 제목이 아이디라 이름이 둘째 줄에 묻힌다.
- 모든 선생님이 "등급 · 선생님"이라 정보가 없는 줄이 반복된다.
