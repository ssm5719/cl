# Empty

목록이나 구역에 보여 줄 것이 없을 때 그 자리를 채운다.

- 위아래 48px(`cl-space-7`), 가운데 정렬, 항목 사이 8px.
- 아이콘 상자 48×48, 반경 12px, 배경 `cl-hover`, 아이콘 `cl-ink-muted`.
- 제목 17px 600(토큰 밖), 설명 `cl-ink-muted` 최대 360px, 버튼은 위 8px 띄운다.
- 설명에는 무엇이 생기면 여기에 나타나는지 쓰고, 할 수 있는 동작이 있으면 버튼 하나를 둔다.

## 기간 화면 (통계 · 기록)

다운로드 현황 · 사용량 현황처럼 기간을 골라 그래프와 표를 함께 보는 화면의 규칙이다.

- 고른 기간에 기록이 0건이면 그래프 카드와 표를 숨기고 Empty **하나만** 카드 안에 둔다(`<section class="cl-card cl-empty-card">`). 같은 문장을 그래프 자리와 표 자리에 두 번 쓰지 않는다.
- 기록이 1건이라도 있으면 Empty 를 쓰지 않는다. 그래프는 빈 날을 0 으로 그리고 표를 보인다.
- 아이콘: 그 화면의 사이드바 메뉴 아이콘(다운로드 현황 = 다운로드, 사용량 현황 = 원그래프), 22px.
- 제목: "{기간}에는 {무엇}이 없습니다" — 예: "2026년 9월에는 다운로드 기록이 없습니다".
- 설명 한 줄: 언제 생기는지 — 예: "사용량은 매일 오전 9시에 전날 것까지 집계됩니다."
- 버튼 하나: [이번 달 보기](이미 이번 기간이면 두지 않는다). 머리의 [엑셀 다운로드]는 비활성.
- 그래프 전용 회색 상자 `cl-chart--empty` 는 쓰지 않는다(Chart 참고).
