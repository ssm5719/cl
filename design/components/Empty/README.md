# Empty

목록이나 구역에 보여 줄 것이 없을 때 그 자리를 채운다.

- 위아래 48px(`cl-space-7`), 가운데 정렬, 항목 사이 8px.
- 아이콘 상자 48×48, 반경 12px, 배경 `cl-hover`, 아이콘 `cl-ink-muted`.
- 제목 17px 600(토큰 밖), 설명 `cl-ink-muted` 최대 360px, 버튼은 위 8px 띄운다.
- 설명에는 무엇이 생기면 여기에 나타나는지 쓰고, 할 수 있는 동작이 있으면 버튼 하나를 둔다.

## 기간 화면 (통계 · 기록)

다운로드 현황 · 사용량 현황처럼 기간을 골라 그래프와 표를 함께 보는 화면의 규칙이다.

- 고른 기간에 기록이 0건이면 그래프 카드와 표를 숨기고 Empty **하나만** 카드 안에 둔다(`<section class="cl-card cl-empty-card">`). 같은 문장을 그래프 자리와 표 자리에 두 번 쓰지 않는다.
- 기록이 1건이라도 있으면 Empty 를 쓰지 않는다. 그래프는 빈 날을 0 으로 그리고 표를 보인다.
- 아이콘: 그 화면의 사이드바 메뉴 아이콘(다운로드 현황 = 다운로드, 사용량 현황 = 원그래프), 22px.
- 제목: "{기간}에는 {무엇}이 없습니다" — 예: "2026년 9월에는 다운로드 기록이 없습니다".
- 설명 한 줄: 언제 생기는지 — 예: "사용량은 매일 오전 9시에 전날 것까지 집계됩니다."
- 버튼 하나: [이번 달 보기](이미 이번 기간이면 두지 않는다). 머리의 [엑셀 다운로드]는 비활성.
- 그래프 전용 회색 상자 `cl-chart--empty` 는 쓰지 않는다(Chart 참고).

## 학원 공개 화면 (2026.10.28)

학원 사이트(전체강좌 · 선생님소개 · Q&A · 자유게시판 등) 목록이 비었을 때의 규칙이다. 클래스 `cl-pub-empty`, 실험실 fix `NE1`.

- 목록이 들어갈 자리에 **회색 점선 상자** 하나 — 1px dashed `cl-control-border`(#D2D2D7), 모서리 `cl-radius-sm`(8), 바탕은 칠하지 않는다.
  - 공개 화면은 테두리 상자를 걷어낸 화면이 많아서, 칠한 회색 상자는 덩어리로 튄다. 점선은 "여기에 들어올 자리"만 가볍게 표시한다.
- 가운데 정렬: 아이콘 28(선 1.5, #A1A1A6) → 문장 `cl-fs-body-sm-pub`(15) 500 `cl-ink-muted` → 필요하면 설명 `cl-fs-caption`(13) #A1A1A6. 사이 8.
- 크기: 목록 자리는 최소 높이 240 · 위아래 48. 댓글처럼 작은 자리는 `cl-pub-empty--sm`(위아래 32, 아이콘 24).
- 옆 칸 높이에 맞춰야 하면(선생님 상세의 담당 강좌) 상자를 `flex: 1` 로 늘린다.
- 비었을 때는 쪽 번호를 숨기고, 개수는 0 으로 둔다. 개수 배지가 따로 있으면(담당 강좌 7) 숨긴다.
- 아이콘은 그 목록을 나타내는 것 하나: 강좌 = 책, 선생님 = 사람, Q&A = 물음 말풍선, 게시판 = 문서, 댓글 = 말풍선.
- 문장은 "없습니다"로 끝내고, 무엇을 하면 채워지는지 알 때만 설명 한 줄. 버튼은 화면에 이미 있으면(질문하기 · 글쓰기) 또 두지 않는다.

| 화면 | 문장 | 설명 |
| --- | --- | --- |
| 전체강좌 | 조건에 맞는 강좌가 없습니다 | 검색어나 분류를 바꿔 보세요 |
| 선생님소개 | 등록된 선생님이 없습니다 | — |
| 선생님 상세 · 담당 강좌 | 담당 강좌가 없습니다 | — |
| Q&A | 아직 질문이 없습니다 | 강의를 듣다 궁금한 점이 생기면 질문해 주세요 |
| 자유게시판 | 아직 게시글이 없습니다 | — |
| 게시글 읽기 · 댓글 | 아직 댓글이 없습니다 | — (`--sm`) |

### 새 목록 화면을 만들 때

1. 그 화면에 들어갈 문장 · 아이콘을 위 표에 한 줄 더한다.
2. 실험실 `lab/night/build_empty.py` 에 같은 한 줄(목록 시작 태그 · 아이콘 · 문장)을 더하고 실행한다 → `screens/<화면>-empty.html` 이 기본 화면에서 다시 만들어진다.
3. `lab/index.html` SCREENS 에 `<화면>-empty` 를 더하고, `fixes.js` 의 NE1 screens 와 머리 · 꼬리말 fix screens 에 같은 id 를 더한다.

기본 화면(`screens/<화면>.html`)을 고친 뒤에는 `build_empty.py` 를 다시 돌리면 빈 화면도 같이 따라온다.
