# 학원 공개 화면 부품

학원 사이트(메인 · 전체강좌 · 강좌 상세 · 강의 보기 · 학원소개 · 선생님 · Q&A · 자유게시판)에서만 쓰는 부품이다. 전체 규칙은 [`../../api/public-ui-rules.md`](../../api/public-ui-rules.md), CSS 는 `../bundle.css` 맨 끝 "학원 공개 화면 부품" 묶음, 실험실 수정 번호는 괄호 안.

상태 표시: **확정** = 개발 반영 대상, **제안** = 실험실에서 보는 중.

## 빈 상태 `cl-pub-empty` (NE1 · 확정)

- 회색 점선 1px `--cl-control-border`, 모서리 8, 바탕 없음. 가운데 아이콘 28 → 문장 15 · 500 → 설명 13.
- 목록 자리 최소 높이 240 · 위아래 48. 작은 자리 `--sm`(위아래 32, 아이콘 24).
- 문장 표 · 새 화면 추가 순서 → [`../Empty/README.md`](../Empty/README.md) "학원 공개 화면".

## 사진 없는 선생님 `cl-avatar-ph` (NI1 · 확정)

- 크기: 머리 계정 32 · 강의 보기 선생님 버튼 28 · 선생님 작은 창 44. 네모 칸(선생님 카드 · 상세)은 같은 아이콘 36px.

### 수강 상태 버튼 `cl-cs-state` · `cl-cs-apply`

- **수강중** `cl-cs-state`: 흰 바탕 · 회색 테두리(`--cl-control-border`) · 회색 체크 · 진회색 글자, 높이 32 · 최소 88. 할 일이 아닌 상태라 조용하게.
  - 마우스를 올리거나 키보드로 고르면 같은 자리 같은 크기에서 빨간 글자 · 테두리 **수강 취소**로 바뀐다(두 글자를 겹쳐 두고 보이기만 바꿈 → 폭이 안 흔들림).
  - 누르면 확인 창: "수강을 취소할까요? / 취소하면 이 강좌의 강의를 볼 수 없습니다." [닫기][수강 취소(위험)].
  - 터치 화면(`hover: none`)은 글자가 바뀌지 않고 바로 확인 창.
- **수강신청** `cl-cs-apply`: 연보라 바탕(`--cl-primary-tint`) · 보라 글자 600 · + 아이콘, 높이 32. 화면에서 보라는 이것에만.
