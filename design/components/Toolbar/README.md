# Toolbar

목록 바로 위에서 검색 · 거르기 · 개수를 한 줄에 모은다.

- 최소 높이 `cl-h-toolbar`(44px), 위아래 8px, 항목 사이 8px, 줄바꿈 허용.
- 검색 칸 `cl-search`: 높이 `cl-h-control`, 너비 220px, 왼쪽 아이콘 자리 32px, 테두리 `cl-control-border`, 포커스 시 `cl-primary` 2px.
- 선택 칸 `cl-select`: 높이 `cl-h-control`, 오른쪽 화살표 자리 30px.
- `cl-toolbar__spacer` 로 왼쪽(검색 · 필터)과 오른쪽(개수 · 쪽마다)을 나눈다.
- 900px 이하에서는 항목마다 한 줄 전체를 쓴다.

## 지금 어긋난 곳

- 강좌 관리(선생님)는 도구 줄 없이 검색 칸이 제목 줄에 있고, 쪽마다 선택은 표 아래에 있다.
- 개수 표시가 화면마다 다르다: 선생님 목록은 도구 줄 오른쪽, 학생 목록은 탭 안, 강좌 관리는 표 아래.
