# TeacherList

관리자 선생님 목록 표. 사람 목록의 기준 화면이다.

- 칸: 아이디 · 이름(사진 28px + 이름) · 휴대폰 · 과목 · 등급 · 등록일 · 메뉴.
- 아이디 칸 `cl-mt-id`: 700, `cl-primary-pressed`, hover 밑줄. 누르면 그 선생님 계정으로 바로 들어간다.
- 이름 칸 `cl-table__title`: 600, hover `cl-primary-pressed`. 누르면 상세.
- 사진 `cl-mt-avatar` 28×28 원형, 없을 때 `cl-hover` 바탕. (미리보기는 사진 대신 첫 글자)

## 지금 어긋난 곳

- 가장 눈에 띄는 칸이 아이디(보라 · 굵게)다. 사람을 찾을 때 보는 건 이름이다 (점검 3).
- 아이디를 누르면 다른 계정으로 들어가는 큰 동작이 바로 실행된다. 같은 동작이 행 메뉴에도 있다.
- 과목 목록의 강좌 이름 칸도 같은 `cl-mt-id` 를 쓴다.
- "미등록" 흐리게, 휴대폰 하이픈 (Table 참고).
