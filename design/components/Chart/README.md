# Chart

대시보드 막대 그래프(로그인 현황, 학습 시간대, 트래픽, 저장량).

- `cl-chart`: 그림 영역 높이 160px + 축 줄. 위 16px 에 최대값(`11px` `cl-ink-muted`).
- 막대: 최대 너비 18px, 위 모서리 3px, 기본 `cl-primary`, 두 번째 계열 `cl-primary-on-dark`, 회색 계열 `#8E8E93`(직접 값). hover 밝기 .9.
- 바닥선 1px `cl-grid-head`, 가운데 눈금 1px `cl-grid-row`.
- 축 글자 11px `cl-ink-muted`. 첫 칸은 왼쪽, 끝 칸은 오른쪽 맞춤.
- 머리: 제목 `cl-md-title` + 범례(`cl-fs-micro`, 8px 네모).
- 빈 칸: 기간 안에 기록 없는 날 · 주 · 달도 0 막대로 그린다(칸을 빼지 않는다).
- 기간 전체가 0건이면 그래프를 그리지 않고 Empty 의 "기간 화면" 규칙을 따른다. `cl-chart--empty`(182px 회색 상자)는 더 쓰지 않는다.

## 지금 어긋난 곳

- 축 · 최대값 11px 이 글자 단계에 없다(최소 단계 12px).
- 대시보드 · 일부 통계 화면이 아직 `cl-chart--empty` 를 쓴다. 다운로드 · 사용량 현황은 표 빈 상태와 같은 문장이 두 번 나온다 → Empty "기간 화면"으로 옮긴다.
- 저장량 구역 아래 설명이 두 줄로 길다.
