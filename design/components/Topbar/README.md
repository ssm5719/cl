# Topbar

작업공간 맨 위 고정 줄: 브랜드, 학기, 알림, 계정.

- 높이 `cl-h-ws-topbar`(56px), 배경 `cl-canvas`, 아래 1px `cl-grid-head`, 화면 위에 고정.
- 왼쪽 브랜드 칸은 사이드바와 같은 너비(`cl-w-ws-sidebar`)와 배경(`cl-sidebar`). 로고 24×24, 학원 이름 600 + 영역 이름(관리자 · 선생님) `cl-fs-micro`.
- 학기 칩 `cl-ws-term`(관리자): 높이 28px, `cl-primary-tint` 바탕, `cl-primary-pressed` 글자 600.
- 알림 `cl-icon-btn`, 새 알림 점 7px `cl-primary`.
- 계정 버튼: 32px 알약, 아바타 + 이름.
- 선생님 화면은 [새로 만들기] 버튼(`cl-btn--primary --sm`)이 있고, 강좌 생성 · 강의 올리기 · 화상 강의 · 과제 · 그룹 · 썸네일 만들기를 한 메뉴에 모은다.
- 900px 이하: 높이 52px, 햄버거 버튼이 나오고 브랜드 칸은 영역 이름만 15px 600 으로 보인다.

## 지금 어긋난 곳

- [새로 만들기]가 꽉 찬 보라라 본문 주 버튼과 겹친다 (점검 3).
- 메뉴 안 이름이 "강좌 생성"과 "~ 만들기"로 섞여 있다 (점검 6).
