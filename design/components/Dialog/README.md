# Dialog

흐름을 멈추고 확인을 받거나 짧은 입력을 받는 창.

- 너비 440px(`--md` 560, `--lg` 820), 안쪽 24px, 반경 `cl-radius-lg`, 그림자 `cl-shadow-float`, 뒤 배경 `rgba(0,0,0,.4)`.
- 제목 17px 700(토큰 밖), 설명 `cl-ink-2`, 줄바꿈 유지.
- 버튼은 오른쪽 아래, 위 24px. 취소(`--text`)가 왼쪽, 실행이 오른쪽.
- 긴 내용은 `--modal`: 머리 56px + 본문 스크롤 + 아래 버튼 줄, 각 경계 1px `cl-grid-row`.
- 확인 문장은 무엇이 어떻게 되는지 쓴다. 버튼 이름은 동작 그대로("삭제").
