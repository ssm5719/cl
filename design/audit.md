# 점검 · 수정 목록

이 시스템을 기준으로 고칠 것을 모은 장이다. 2026-10-19 받은 화면 5개(대시보드, 선생님 목록, 학생 목록, 과목 목록, 강좌 관리(선생님))와 CSS 4개를 기준으로 했다.

- **현재**는 지금 코드 값, **바꿀 값**은 제안, **[정할 것]**은 아직 결정 전이다.
- 결정이 나면 여기서 지우고 README · 토큰 · 컴포넌트 안내에 옮긴다.
- 다크모드는 7번(토큰 정리)이 끝난 뒤에 한다.

## 1. 화면 머리 틀

목록 화면은 위에서부터 이 순서로 쌓는다. 없는 줄은 빼고, 순서는 바꾸지 않는다.

```
상위 메뉴 (cl-page__parent)
제목 ─────────────────────────── [보조 버튼] [주 버튼]
설명 1줄 (cl-page__meta)
(탭 — 있을 때만)
도구 줄: [검색] [필터] [초기화] ──────── [보기 전환] [개수 · 쪽마다]
```

- 검색은 도구 줄 왼쪽 첫 칸. 제목 줄에 두지 않는다.
- 보기 전환은 도구 줄 오른쪽. 제목 줄에 두지 않는다.
- 주 버튼은 제목 줄 맨 오른쪽, 하나만.
- 설명은 한 줄. 넘치면 도움말로 옮긴다.

| 화면 | 상위 메뉴 | 주 버튼 | 설명 | 검색 | 보기 전환 | 개수 |
| --- | --- | --- | --- | --- | --- | --- |
| 대시보드 | 없음 | 없음 | 없음 | — | — | — |
| 선생님 목록 | 사용자 관리 | 선생님 생성 | 2문장 | 도구 줄 | **제목 줄** | 도구 줄 오른쪽 |
| 학생 목록 | 사용자 관리 | **없음**(엑셀 2개) | 2문장 | 도구 줄 | 없음 | **탭 안** · 쪽마다는 도구 줄 |
| 과목 목록 | 강좌 관리 | 과목 추가 | **3문장** | 없음 | 없음 | 왼쪽 목록 |
| 강좌 관리 (선생님) | **없음** | 강좌 생성 | **없음** | **제목 줄** | **제목 줄** | **표 아래** |

[정할 것] 대시보드처럼 기간을 고르는 화면은 이 틀의 예외로 둘지.

## 2. 글자 단계

토큰 밖 크기를 단계 안으로 넣는다. 크기는 "코드에 직접 적은 크기" 묶음에서 볼 수 있다.

| 현재 | 몇 곳 | 바꿀 값 | 예 |
| --- | --- | --- | --- |
| 14px 700 (제목 자리) | 1 | `cl-fs-section-title` 16px | 대시보드 섹션 제목 `.cl-md-title` |
| 11px | 7 | `cl-fs-micro` 12px | 차트 축 · 최대값, 단축키 표시 |
| 11.5px | 1 | `cl-fs-micro` 12px | 진도 히트맵 칸 |
| 13.5px | 1 | `cl-fs-ui` 14px | 이미지 저장소 파일 이름 |
| 14px 직접 | 22 | `cl-fs-ui` | 값은 같고 토큰만 연결 |
| 14.5px | 2 | `cl-fs-ui` 14px 600 | 강좌 이름 `.cl-tc-course__title` |
| 15px | 12 | `cl-fs-section-title` 16px | 카드 제목, 목록 행 제목, 큰 버튼 |
| 17px | 6 | 새 단계 18px | 대화상자 · 빈 상태 제목, 선생님 카드 이름 |
| 18px | 1 | 새 단계 18px | 숫자 상자 값 `.cl-stat__value` |
| 22px | 1 | 새 토큰 `cl-fs-stat` 22px | 숫자 띠 값 `.cl-kpi dd` |

[정할 것] 17px 자리를 새 단계 18px(`cl-fs-title-lg`)로 올릴지, 16px 로 내릴지.

## 3. 보라색 사용

한 화면에 꽉 찬 보라(`cl-btn--primary`)는 하나만 둔다.

| 곳 | 현재 | 바꿀 값 |
| --- | --- | --- |
| 선생님 상단 바 [새로 만들기] | `cl-btn--primary --sm` | `cl-btn--tint --sm` |
| 선생님 목록 아이디 칸 | 첫 칸, 700, `cl-primary-pressed`, 누르면 그 계정으로 들어감 | 둘째 칸, 400, `cl-ink-muted`, 누르는 동작 없음 |
| 선생님 목록 이름 칸 | 둘째 칸, 600 | 첫 칸(`data-primary`), 사진 + 이름 600 `cl-ink`, 누르면 상세 |
| 계정으로 들어가기 | 아이디 칸 + 행 메뉴 | 행 메뉴에만 |
| 과목 목록 강좌 이름 | `cl-mt-id` (보라 굵게) | `cl-table__title` |
| "미등록" | `cl-ink` | `cl-ink-muted` |
| 휴대폰 | 01067060246 | 010-6706-0246 |

[정할 것] 계정으로 들어가기를 자주 쓴다면 이름 칸 오른쪽에 작은 [들어가기] 버튼(`cl-btn--ghost --xs`)을 둘지.

## 4. 상태 색 · 대시보드

상태는 글자(점) 색과 연한 배경을 한 쌍으로 쓴다. 같은 목록에서 어떤 상태만 배경이 있으면 안 된다.

| 곳 | 현재 | 바꿀 값 |
| --- | --- | --- |
| 확인 필요 · 주의 항목 | 배경 `#FFF9F0` | `cl-warning-bg` |
| 확인 필요 · 위험 항목 | 배경 없음 | `cl-danger-bg` |
| 확인 필요 순서 | 들어온 순서 | 위험 → 주의 → 그 밖 |
| 갱신 안내 | '확인 필요' 구역 맨 아래 | 숫자 띠 '전체 사용 용량' 보조 줄: "매일 09시 갱신" |
| 빈 그래프 | 182px `cl-parchment` 상자 | 배경 없이 축선만, 가운데 문장 한 줄 (`cl-ink-muted`) |
| 저장량 설명 | 그래프 아래 두 줄 | 제목 옆 도움말로 |

주의 항목에만 배경이 들어가는 이유: 선택자 `.cl-md-need.is-warning:first-child` 가 "첫 항목만"을 노렸지만, 항목마다 `<li>` 안 첫째 요소라 모든 주의 항목에 걸린다.

## 7. 토큰 정리

`base · components · manager · teacher.css` 에 색이 84번 직접 적혀 있다.

| 종류 | 개수 | 처리 |
| --- | --- | --- |
| `#fff` / `#FFFFFF` | 23 | 글자면 새 토큰 `cl-on-ink`, 바탕이면 `cl-canvas` |
| 토큰에 이미 있는 값 (#C5221F, #F4F4F6, #7A35D0, #B78AF7, #1D1D1F, #AEAEB2, #E2D3FB, #EDEDF0, #F0F0F2, #F7F7F8, #F5F5F7) | 32 | 해당 토큰으로. 화면은 그대로다 |
| 새 토큰이 필요한 값 (아래 표) | 20 | 새 토큰으로 |
| 한두 곳에서만 쓰는 값 | 9 | [정할 것] |

새 토큰 · 나누는 토큰:

| 토큰 | 현재 | 바꿀 값 | 이유 |
| --- | --- | --- | --- |
| `cl-primary` | 버튼 배경과 글자를 같이 씀 | `cl-primary-fill` #904AE8 / `cl-primary-text` #7A35D0 | #904AE8 글자는 4.85:1 로 작업공간 기준 6:1 미달 |
| `cl-primary-pressed` | 눌림 + 링크 글자 + 현재 메뉴 글자 | 눌림 전용. 글자는 `cl-primary-text` | 이름과 용도가 다르다 |
| `cl-on-ink` | 없음 | #FFFFFF | 진한 바탕(보라 · 먹색 · 빨강) 위 글자. 다크모드에서 이것만 바꾼다 |
| `cl-primary-tint-hover` | #EADDFB, #E9DDFB | #EADDFB | 같은 용도, 두 값 |
| `cl-danger-pressed` | #A8191A | #A8191A | 위험 버튼 눌림 |
| `cl-row-hover` | #FAFAFB, #FAFAFC, #F8F8FA | #FAFAFB | 표 · 목록 행 hover |
| `cl-track` | #ECECEF 6곳 | #ECECEF | 진도 · 점수 막대 바탕 |
| `cl-nav-hover` | #EFEFF1 3곳 | #EFEFF1 | 사이드바 hover |
| `cl-scrim` | rgba(0,0,0, .32 / .4 / .45) | rgba(0,0,0,.4) | 대화상자 · 서랍 뒤 |

`cl-primary` 는 옮기는 동안 `cl-primary-fill` 의 별칭으로 두고, 다 옮긴 뒤 지운다.

[정할 것] 한두 곳에서만 쓰는 값

- #FFF9F0(확인 필요 주의 배경), #FFF6F5(진도 위험 배경) → `cl-warning-bg` · `cl-danger-bg` 로 합칠지
- #4A1F8C, #2D1060(히트맵 칸 위 글자) → `cl-heat-1-ink` · `cl-heat-2-ink` 로 둘지
- #8E8E93(차트 회색 막대) → `cl-ink-faint` 로 합칠지
- #FDE9C8(학기 칩 경고 hover), #FBF8FF(안내 상자 배경), #FFB4AB(진한 바탕 위 위험 글자)
