# Icons

작업공간 사이드바 · 상단 바 · 버튼에서 쓰는 선 아이콘을 화면에서 그대로 옮겼다.

- 24 격자, 선 굵기 1.75, 둥근 끝 · 둥근 모서리.
- 화면에서는 `stroke="currentColor"` 로 글자색을 따른다. 파일을 `<img>` 로 넣으면 검은 선으로 보인다.
- 파일 이름은 쓰는 자리를 따랐다: `student` = 학생 목록, `course` = 강좌 목록, `upload` = CMS 콘텐츠 관리, `more` = 행 메뉴(⋯) 등.

## 동영상 플레이어 (2026.10.29)

- `player-play` · `player-pause` · `player-back-10` · `player-forward-10` · `player-volume` · `player-mute` · `player-fullscreen` · `player-fullscreen-exit` — VideoPlayer 조작 줄 아이콘.
- 영상 위에서 22px 로 보이므로 선 굵기 2(작업공간 1.75 보다 굵게). 재생 · 일시정지와 스피커 몸통은 채운 모양. 화면에서는 흰색(`currentColor`). 파일을 `<img>` 로 넣으면 검은 모양으로 보인다.
- `player-back-10` · `player-forward-10` 의 "10" 은 SVG 글자(sans-serif 700)다.
