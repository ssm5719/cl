### NA1 · 과제 통계 창 — 채점 전 0 · 순위 1 · '미채점 · 0~20점' 을 바로잡기

- 화면: 과제 통계 (창)
- 실험실 화면 파일: `lab/screens/t-assign-stats-dlg.html`
- 층: 화면별 · 작업: 프론트 수정
- 지금: 아무도 채점하지 않았는데 총합 · 평균 · 최고 · 최저가 0 으로 보이고, 순위표에서 미채점 학생 7명이 모두 '1위'. 점수 분포의 '미채점 · 0~20점' 막대가 미채점을 0점대로 읽히게 함. 미제출 · 미채점 막대가 보라라 나쁜 값이 가장 눈에 띔
- 바꿀 모습: 채점한 학생이 없으면 숫자 대신 — + 안내 한 줄. 분포는 '0~20점' 과 '미채점' 을 나눈다. 순위는 채점한 학생만 매기고 미채점은 — (회색). 미제출 · 미채점 막대는 회색(cl-mark-muted), 보라는 제출 · 점수 막대에만
- 보이는 조건: 선생님 → 과제 관리 → 행 ⋯ → 과제 통계 (또는 채점 화면 [통계])
- 마크업 · 스크립트: teacher/assignment 통계: 점수 계산은 채점한 학생만(채점 0명이면 KPI 를 '—'). 분포 구간에 '미채점' 을 따로 두고, 순위는 점수 있는 학생만 dense rank, 미채점은 순위 칸 '—'. 막대 class: 미제출 · 미채점은 <span class="is-muted">
- 참고: 테스트 사이트(장현석 선생님 계정으로 들어가기)에서 확인 2026.10.29. 실험실에 없던 과제 있는 목록 · 채점 · 통계 · 지금 마감 · 수정 확인 화면을 함께 추가

rows.forEach(function (tr) { if (/미채점/.test(tr.children[2].textContent)) { tr.children[0].textContent = '—'; tr.children[0].classList.add('cl-muted'); tr.children[2].classList.add('cl-muted'); } });
