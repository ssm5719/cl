### AM5 · 히어로 제목 최대 104 → 80px, 토큰으로

- 화면: 학원 메인 · 기본형 (선생님 로그인), 학원 메인 · 대시보드형 (선생님 로그인)
- 실험실 화면 파일: `lab/screens/a-main.html` · `lab/screens/a-main-dash.html`
- 층: 토큰 · 작업: CSS만
- 지금: 학원 이름이 `clamp(40px, 7.2vw, 104px)` 로 그려져 넓은 화면에서 104px 까지 올라간다. 크기가 화면 CSS 에 직접 적혀 있고 토큰(`--cl-fs-hero`)은 104px 이라는 숫자만 들고 있어 서로 따로 논다. 104px 는 짧은 영문 단어에 맞춘 크기라, "언어비전국어전문학원" 같은 10글자 한글 학원 이름은 가로 1040px 을 먹어 본문 폭을 꽉 채운다. 지금 두 학원은 슬라이드를 쓰거나 사진이 있어 가려져 있을 뿐, 슬라이드도 사진도 없는 학원에서는 바로 드러난다
- 바꿀 모습: 최대 80px 으로 낮춘다. 그리고 크기를 화면 CSS 에서 빼고 토큰이 `clamp` 까지 들고 있게 한다 — 화면은 `var(--cl-fs-hero)` 만 읽는다. 한글 10글자면 800px 로, 본문 폭 1240px 안에 한 줄로 들어간다. 15글자 학원도 두 줄에서 멈춘다
- 참고: 사진이 같이 있는 히어로는 따로 `clamp(40px, 4.4vw, 56px)` 로 한 번 더 줄이고 있어 그대로 둔다. 이 값도 토큰(`--cl-fs-page-title-pub` 56px)에 올리면 화면 CSS 에서 숫자가 완전히 사라진다 — 글자 단계 정리(181곳) 때 같이 옮긴다.

```css
/* 크기는 토큰이 들고, 화면은 읽기만 한다 */
.cl-scope { --cl-fs-hero: clamp(40px, 5.6vw, 80px); }
.cl-home-hero__title { font-size: var(--cl-fs-hero); }
```

### AM6 · 모서리 둥글기 — 16 · 12 · 10 · 8 네 값을 6 · 8 두 단계로

- 화면: 학원 메인 · 기본형 (선생님 로그인), 학원 메인 · 대시보드형 (선생님 로그인)
- 실험실 화면 파일: `lab/screens/a-main.html` · `lab/screens/a-main-dash.html`
- 층: 토큰 · 작업: CSS만
- 지금: 학원 메인의 네모난 면이 16 · 12 · 10 · 8px 네 값을 쓴다. 그중 **16px 이 7곳**(히어로 사진 · 선생님 사진 · 갤러리 · 슬라이드 · 배너 · 대시보드 타일)인데 토큰 척도(4 · 8 · 10 · 12 · pill)에 없는 값이다. 같은 화면에서 사진은 16, 카드는 10, 썸네일은 8 이라 면마다 모서리가 다르게 깎여 있다
- 바꿀 모습: 작은 썸네일은 6px, 나머지 네모 면은 모두 8px. 6px 은 새 토큰 `--cl-radius-2xs` 로 등록한다 — 배지 · 메뉴 항목 · 보기 전환 · 작은 버튼이 이미 6px 을 직접 적고 있어, 디자인시스템 점검 7번의 "[정할 것] 6px 을 토큰으로 올릴지"를 같이 정리하는 셈이다. 버튼 · 칩 · 아바타 · 아이콘 동그라미(pill)는 모양 자체가 원이라 건드리지 않는다
- 참고: 정할 것 두 가지. ① 분류 카드를 10 → 8 로 내리면 작업공간 카드(`--cl-radius-md` 10px)와 어긋난다 — 공개 화면 카드 8, 관리자 카드 10. 끝까지 맞추려면 작업공간 카드도 8로 내려야 하고 그건 관리자 · 선생님 · 학생 전체에 영향이 간다. 공통층 넘길 때 같이 정한다. ② 슬라이드(1200×460)와 배너는 실험실 화면에 아직 없어 눈으로 확인하지 못했다 — CSS 에는 넣었지만 실제 화면에서 한 번 보고 확정한다.

```css
/* 6px 을 척도에 등록한다 (배지 · 메뉴 항목 · 보기 전환 · 작은 버튼도 쓰는 값) */
.cl-scope { --cl-radius-2xs: 6px; }
/* 작은 썸네일만 6px */
.cl-home-course__thumb { border-radius: var(--cl-radius-2xs); }
/* 나머지 네모 면은 8px — 16px 을 쓰던 7곳 포함 */
.cl-home-cat,
.cl-home-teacher,
.cl-home-teacher__photo,
.cl-home-hero__media,
.cl-home-gallery img,
.cl-home-gallery > *,
.cl-home-banner,
.cl-home-slider__viewport,
.cl-home-split__fallback,
.cl-home-tile { border-radius: var(--cl-radius-sm); }
/* 모바일에서 썸네일이 가로 전체가 되면 8px (지금은 12px) */
@media (max-width: 900px) { .cl-home-course__thumb { border-radius: var(--cl-radius-sm); } }
```

- 바꿀 모습: 1100px 이하에서 **로고가 있는 학원만** 학원 이름 글자를 숨긴다. 로고 그림에 이미 학원 이름이 들어 있는 경우가 많아 태블릿에서는 로고만으로 충분하고, 그만큼(약 154px) 메뉴가 숨 쉴 자리가 생긴다. 로고 없이 첫 글자 네모(`cl-pub-brand__mark`)만 쓰는 학원은 이름을 숨기면 학원을 알 수 없으므로 `:has()` 로 걸러 그대로 둔다
- 참고: 가장 긴 경우(학원 이름 10자 + 메뉴 5개 중 "수업커뮤니티" 포함)로 재 봤다. 901px 에서 -90px(겹침) → +64px(여유)로 바뀐다. 다른 방법도 재 봤다 — ① 메뉴 간격을 `clamp` 로 줄이기는 -31 → -19 로 거의 효과가 없다(겹치는 양이 글자 폭이라서). ② 브랜드를 `flex: 0 1 auto` 로 줄어들게 해도 `.cl-pub-nav { flex: 1 }` 이 먼저 줄어들어 브랜드에는 압력이 가지 않는다. ③ 서랍을 1024px 부터 열면 해결되지만 이름이 짧은 학원까지 태블릿에서 메뉴 줄을 잃는다. 이름을 접는 쪽이 메뉴를 살리면서 가장 적게 바꾼다. [정할 것] 로고에 학원 이름이 없는 학원은 태블릿에서 이름이 사라진다 — 관리자 설정에 "로고에 학원 이름이 들어 있나요" 체크를 두면 정확해진다.

```css

@media (max-width: 1100px) {
  .cl-pub-brand:has(.cl-pub-brand__logo) .cl-pub-brand__name { display: none; }
}
```

### AM12 · 분류별로 찾기 — 첫 칸 특별 대우 없애고 칸 수를 폭에 맡기기

- 바꿀 모습: 모든 분류를 같은 흰 카드로 둔다. 분류는 서로 동등한 선택지라 하나만 칠할 근거가 없고, 보라는 버튼으로 돌아간다. 칸 수는 `auto-fill` 로 폭에 맡겨 몇 개가 되든 격자가 깨지지 않는다. 1~3개일 때는 격자 자체를 좁혀(300 · 620 · 940px) 카드가 늘어나 보이지 않게 한다. 2개 · 10개 모두 어색하지 않다. 분류가 하나뿐이면 섹션을 숨긴다 — 고를 게 하나면 "분류별로 찾기" 가 성립하지 않고, 그 분류는 대표 강좌와 전체강좌에서 이미 보인다

### AM15 · 분류 카드 — 마우스를 올리면 아이콘이 올라오고 [강좌 보기]가 움직이기

- 실험실 화면 파일: `lab/screens/a-main.html` · `lab/screens/a-main-dash.html`
- 층: 화면별 · 작업: 프론트 수정
- 지금: 분류 카드는 제목 · 하위 분류 한 줄 · [강좌 보기]뿐이라 `min-height: 168px` 안이 빈다. 마우스를 올려도 테두리 색만 한 번 바뀐다
- 바꿀 모습: 오른쪽 아래에 36×36 아이콘을 둔다. 평소에는 흐리게(`opacity: .45`) 깔려 있다가, 마우스를 올리면 **4px 올라오며 또렷해지고**, 같은 속도로 [강좌 보기]가 오른쪽으로 10px 움직이고 테두리도 보라로 바뀐다. 셋 다 150ms ease-out — 디자인시스템이 정한 "버튼 · 링크의 색과 크기 변화는 150ms ease-out" 그대로다. 아이콘은 서비스 아이콘 세트에서 세 개(책 · 재생 · 사람들)를 쓰고, **분류 이름으로 정해 고정**한다
- 마크업 · 스크립트: `.cl-home-cat` 안 맨 끝에 `<svg class="cl-home-cat__deco" ...>` 를 넣는다. 아이콘은 분류 이름의 글자 코드 합을 아이콘 수로 나눈 나머지로 고른다 — 서버에서 분류마다 아이콘 이름을 내려주면 그 값을 쓰는 쪽이 더 낫다(관리자가 고를 수 있게).
- 참고: **랜덤이 아니라 고정이다.** 새로고침마다 바뀌면 "이 아이콘이 무슨 뜻이지" 하고 의미를 찾게 되는데 아무 의미가 없다 — 의미 없는 신호는 장식이 아니라 소음이다. 이름으로 정하면 겉보기 다양함은 그대로이면서 같은 분류는 언제나 같은 아이콘이다. 색은 `--cl-heat-1`(#E2D3FB), 흰 카드 위 1.35:1 로 질감처럼 깔린다 — `--cl-primary-tint`(1.1:1)는 거의 안 보이고 `--cl-primary-on-dark`(2.6:1)는 제목과 경쟁한다. 선 굵기만 1.25 로 시스템 값(1.75) 밖인데, 읽는 아이콘이 아니라 바탕 질감이라 둔 예외다. `prefers-reduced-motion` 을 켠 사람에게는 움직이지 않고 아이콘이 그대로 보인다. 평소에도 흐리게 보여서 카드가 비어 보이지 않고, 마우스를 올리면 또렷해지며 살짝 올라온다. hover 할 때만 나타나는 안도 그려 봤지만 평소의 허전함이 그대로라 이쪽으로 정했다.

```css

.cl-home-cat { position: relative; }

  width: 36px; height: 36px;
  color: var(--cl-heat-1);
  opacity: .45; transform: translateY(0);
  transition: opacity 150ms ease-out, transform 150ms ease-out;
  pointer-events: none;
}
.cl-home-cat__go { transition: transform 150ms ease-out, color 150ms ease-out; }
.cl-home-cat:hover .cl-home-cat__deco { opacity: 1; transform: translateY(-4px); }
.cl-home-cat:hover .cl-home-cat__go { transform: translateX(10px); }
/* 움직임 줄이기를 켠 사람에게는 움직이지 않고 그대로 보여 준다 */
@media (prefers-reduced-motion: reduce) {
  .cl-home-cat, .cl-home-cat__deco, .cl-home-cat__go { transition: none; }
  .cl-home-cat:hover .cl-home-cat__deco { transform: none; }
  .cl-home-cat:hover .cl-home-cat__go { transform: none; }

```
