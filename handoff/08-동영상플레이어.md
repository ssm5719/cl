### NL1 · 동영상 플레이어 조작 줄 — 영상 위 그라데이션 · 진행 막대 위로 · 보라 진행 · 배속 꺼내기 · 정지 빼기

- 화면: 동영상 플레이어 (LABY · 모든 강의 영상)
- 실험실 화면 파일: `lab/screens/player-laby.html`
- 층: 화면별 · 작업: 프론트 수정
- 지금: 영상 아래를 진회색 띠(#222)가 덮고, 진행 막대는 그 띠 맨 아래 가는 회색 선(#999 · 4px)이라 지금 위치가 잘 안 보임. 재생 · 정지가 따로 있고 음량 막대(120)가 늘 펼쳐져 있음. 플레이어에 재생속도 · 챕터가 있는데 설정 버튼이 숨겨져 배속을 쓸 수 없음. 색은 흰색 · 회색뿐
- 바꿀 모습: 조작 줄을 영상 위 그라데이션으로 띄우고 진행 막대를 버튼 위로(본 부분 학원 대표색 · 올리면 굵어지고 손잡이 · 시간 말풍선). 정지 빼고 10초 뒤로 · 앞으로 추가, 음량 막대는 올릴 때만, 오른쪽에 [1.0×] 배속 버튼(0.5 ~ 2.0), 멈추면 가운데 큰 재생 버튼 재생 중 마우스를 3초 멈추거나 밖으로 나가면 조작 줄이 사라지고, 움직이면 다시 보임(유튜브처럼)
- 보이는 조건: 강의 영상을 재생하는 모든 곳(학원 강의 보기 · 선생님 강의 미리보기 · 관리자 콘텐츠 미리보기). 영상 위에 마우스를 올리면 보임
- 확인하는 길: 관리자 → 콘텐츠 목록 → 콘텐츠 제목 → 미리보기 창 영상 위에 마우스
- 마크업 · 스크립트: 대상은 학원 사이트가 아니라 LABY 플레이어(cms.atedu.co.kr · video-common.css · lab.View.js). 플레이어는 cl-tokens.css 를 불러오지 않으므로 토큰 값을 그대로 쓰거나 cl-tokens.css 를 함께 불러온다: 본 부분 = 학원 대표색(--cl-primary, 기본 #904AE8 — 학원 색은 플레이어 주소 파라미터로 넘김), 흰 글자 #FFFFFF, 메뉴 선택 글자 #B78AF7.

2) .progress-gage-wrap 을 .player-controller-box 앞(위)으로 옮기고, 누르는 높이 16 · 막대 4(올리면 6) · 동그라미 손잡이 14(올리면 보임) · 올린 위치 시간 말풍선. role="slider", 키보드 ← → 5초.
3) .btn-stop 삭제. .btn-play 옆에 10초 뒤로 · 앞으로 버튼(이미 있는 time-jump-left/right 동작 재사용).
4) .btn-mute 와 .volume-wrap 을 한 묶음으로, 막대는 마우스를 올리거나 키보드로 들어갈 때만 펼침(72). 스피커를 누르면 음소거 — 아이콘이 X 스피커로 바뀌고(aria-pressed="true", 이름 "음소거 해제") 막대는 0, 다시 누르면 이전 음량으로. 음량을 막대로 0 까지 내려도 같은 X 아이콘.
5) 숨겨진 .btn-setting 의 재생속도를 오른쪽 글자 버튼 [1.0×] 로 꺼냄 — 위로 열리는 목록 0.5 · 1.0(보통) · 1.2 · 1.5 · 2.0. 고른 값은 학생별로 기억(localStorage).
6) 멈춘 상태에서 가운데 72 원 재생 버튼(.btn-center-play).

var show = function () { w.classList.remove('is-idle'); clearTimeout(idleT); };
var hideLater = function (ms) { clearTimeout(idleT); idleT = setTimeout(function () { if (canHide()) w.classList.add('is-idle'); }, ms); };
w.addEventListener('mousemove', function () { show(); hideLater(IDLE); });
w.addEventListener('mouseleave', function () { clearTimeout(idleT); if (canHide()) w.classList.add('is-idle'); });
w.addEventListener('focusin', show);
w.addEventListener('touchstart', function () { if (w.classList.contains('is-idle')) { show(); hideLater(IDLE); } }, { passive: true });
new MutationObserver(function () { if (w.dataset.playerState !== 'playing') show(); else hideLater(IDLE); }).observe(w, { attributes: true, attributeFilter: ['data-player-state'] });
