## 지킬 규칙

- **공통 부품 먼저.** 모양은 `components.css` 의 공통 부품(Button · Link · Status · Tabs · Composer · MiniList · Popover · FileCard · Empty · Avatar)으로만 만든다. 화면 전용 클래스는 놓는 자리(간격 · 칸 배치)만 정한다. 옛 클래스 → 공통 클래스 표는 `design/components/Button/README.md`.
- **값은 토큰으로만.** 글자 크기 · 모서리 · 색 · 간격은 `var(--cl-…)`. `font-size: 14px`, `#fff` 처럼 직접 쓰지 않는다. 새 값이 필요하면 토큰부터 추가한다.
- **마크업 항목은 결과를 설명한 것**이다. 실험실 스크립트(`dom`)는 확인용이고, 실제로는 서버 템플릿 · 화면 JS(list.js 등)에서 같은 결과를 만든다.
- **이 문서에 없는 화면 · 동작은 바꾸지 않는다.** `06-제안-확인메모.md` 의 항목도 바꾸지 않는다.
- "보이는 조건"이 적힌 항목은 설정 · 상황에 따라서만 보인다(예: 메인 대시보드형, 빈 목록, 선생님 계정으로 들어가기). "확인하는 길"을 따라 직접 열어 본다.
- "CSS 범위"가 적힌 항목은 그 선택자 안에서만 적용한다.
- 움직임은 `prefers-reduced-motion: reduce` 에서 끈다.
- 문구: 만드는 버튼은 "만들기", 날짜는 `2026.10.20`, 숫자 뒤 단위는 붙여 쓴다(14명, 3건).
