# 1차 테스트 · 2026학년도 10월 고2 학력평가 국어 · 영어

실행일 2026-10-28 · 선생님 검토 전 (AI 자동 검사까지만 끝난 상태)

## 어떻게 돌렸나

- 이 작업 환경에는 API 키가 없어서, `aitest.py` 와 **같은 단계 · 같은 지시문(`prompts.py`)** 을 세션 안의 Claude 작업자가 대신 수행했습니다. 기본 모델(`claude-opus-5-5`)과 같은 계열입니다.
- 단계마다 다른 작업자가 맡았습니다(나누기 / 만들기 / 정답 가리고 다시 풀기). 다시 푸는 작업자는 정답 · 해설 파일을 볼 수 없게 했습니다.
- 시험지 · 만든 문항 · 검토 화면은 저작권 때문에 저장소에 올리지 않습니다(`outputs/eng-2610`, `outputs/kor-2610`).

## 1. 시험지 통째로 나누기

| | 영어 | 국어 |
|---|---|---|
| 나눈 단위 | 25개 (18~45번, 듣기 제외) | 15개 (1~45번 전부) |
| 문항 번호 누락 · 중복 | 없음 | 없음 |
| 그림 · 표가 있어야 푸는 단위 | 1개 (25번 도표) | 3개 (4~6 설문표, 17~20 토지 그림, 21~23 그래프) |
| AI 가 '확실하지 않음' 표시 | 0개 | 1개 (8번 중세 국어 옛글자) |
| 걸린 시간 | 약 2분 | 약 10분 |

- 2단 편집이라 글자층을 그대로 뽑으면 왼쪽 · 오른쪽 단이 섞이는데, 두 과목 모두 바르게 다시 이었습니다. 밑줄 · ①~⑤ 위치 · (A)(B)(C) 묶음 · <보기> · [A] 구간 표시도 살렸습니다.
- 국어 작업자는 열 단위 글자 추출 같은 보조 도구를 썼습니다. 실제 API 한 번 호출은 PDF 를 직접 읽기 때문에, **API 로 돌렸을 때 나누기 정확도는 따로 확인해야 합니다.**
- 그림 단위는 기본 설정상 문항 만들기에서 빠집니다. 국어는 독서 3묶음 중 2묶음에 그림 문항이 섞여 있어, 그림을 다루는 방법이 1차 범위에서 꽤 중요합니다.

| 걸린 시간 | 약 6분 (한 작업자가 차례로. API 는 동시 실행이라 더 짧음) | 약 5분 |

## 3. 자동 검사

| | 영어 | 국어 |
|---|---|---|
| 정답 가리고 다시 풀었을 때 같은 답 | 20 / 20 | 12 / 12 |
| 근거 문장이 지문에 그대로 있음 | 20 / 20 | 12 / 12 |
| 복수 정답 · 정답 없음 등 지적 | 0 | 0 |
| 정답 번호 분포 (1~5번) | 2 · 4 · 4 · 5 · 5 | 2 · 3 · 2 · 3 · 2 |

자동 검사로는 걸러진 문항이 하나도 없습니다. 다만 **이것만으로는 '쓸 수 있는 문항' 비율을 알 수 없습니다.** 자동 검사가 놓치는 문제(난이도, 원래 문항과 너무 비슷함, 형식)는 선생님 검토로만 보입니다.

## 4. 직접 훑어보며 눈에 띈 점 (검토 전 의견)

좋은 점
- 영어는 유형마다 수능 형식을 정확히 따랐습니다. 어법 · 어휘는 밑줄 위치를 새로 잡았고, 순서 · 삽입은 단락을 다시 나눠 새 문항을 만들었습니다.
- 국어 독서 3점 문항은 원래 그림 문항 대신 숫자 조건이 담긴 새 <보기>를 만들었고, 계산까지 맞았습니다(건축법 17~20).
- 해설에 정답 근거와 헷갈리는 오답의 이유가 함께 들어 있습니다.

걸리는 점 (선생님 판단 필요)
- **원래 시험 정답이 드러나는 문항**: 31 · 33번 빈칸을 원래 정답으로 채운 채 다른 곳에 새 빈칸을 냈습니다. 원래 시험을 푼 학생에게는 힌트입니다.
- **선택지 언어**: 영어 '글의 목적' · '요지' 변형 중 선택지를 영어로 쓴 문항이 있습니다(수능은 한국어 선택지).
- **원래 문항과 비슷함**: 문장 삽입 변형은 원래 주어진 문장을 지문에 돌려놓고 다른 문장을 뺀 방식이라, 원래 문항을 본 학생은 쉽게 풀 수 있습니다.
- **문학 해석형**: 현대시 · 고전소설의 감상 문항은 해석이 갈릴 수 있어 선생님 판정이 꼭 필요합니다.

## 5. 남은 일

1. 영어 · 국어 선생님이 `review.html` 로 검토 → `aitest.py report` 로 판정(A 일괄 생성 / B 지문 골라 돌리기 / C 보류).
2. 위 '걸리는 점'이 실제로 감점 요인이면 `prompts.py` 에 규칙 추가 후 2차 실행:
   - 원래 문항의 정답(빈칸 정답, 원래 주어진 문장)을 새 문항 지문에 드러내지 않는다.
   - 영어 목적 · 요지 · 주장 · 심경 유형은 한국어 선택지로 쓴다.
3. API 키가 생기면 같은 시험지로 `aitest.py all` 을 한 번 돌려 나누기 정확도 · 비용 · 대기 시간을 실제 값으로 확인.
