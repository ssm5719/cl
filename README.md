# cl

클라우드러닝 리디자인 작업 저장소.

| | |
| --- | --- |
| [`design/`](design/) | 디자인시스템 — 관리자 · 선생님 · 학생 · 학원 페이지가 함께 쓰는 토큰 · 글자 · 간격 · 부품 규칙 |
| [`lab/`](lab/) | 수정 실험실 — 배포 없이 "지금 화면"과 "수정안"을 전환해 비교하는 정적 페이지. 실제 서비스 코드가 아닙니다 |
| [`aitest/`](aitest/) | 시험 출제(AI 문제 생성) 기능 작업 모음 — 지금은 실제 시험지로 문항을 만들고 선생님 검토 결과로 기능 범위를 정하는 테스트 도구. 페이지 코드와 별개입니다 |

`design/` 이 규칙, `lab/` 이 그 규칙을 화면에 적용한 미리보기입니다. 개발자에게 넘길 때는 `lab/` 로 화면을 보여 주고, 값은 `design/tokens.css` 를 쓰면 됩니다.
